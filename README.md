# -rvore-Bin-ria-com-Aprendizado-Simple-Akinator-
Árvore Binária de Decisão em C com expansão dinâmica de nós em tempo de execução. O sistema utiliza lógica interativa para aprender com o utilizador, transformando nós folha em nós de pergunta ao falhar. Implementa alocação dinâmica (malloc/free), structs, enums, recursão e travessia Pré-Ordem (Pre-Order).
